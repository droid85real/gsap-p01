## ⚙️ Tech Stack

* React
* GSAP
* ScrollTrigger
* SplitText
* Vite
* Vercel (deployment)

## ✨ Features

* Scroll-linked animation timelines
* GSAP tweens with custom easing
* Staggered text reveals using SplitText
* Section-based sequencing with ScrollTrigger
* Responsive animation logic for mobile
* Optimized smooth transitions and performance

## 🧠 What I Practiced

* Timeline orchestration
* ScrollTrigger start/end control
* Easing and stagger tuning
* Component-level animation structure
* Performance considerations for heavy motion
